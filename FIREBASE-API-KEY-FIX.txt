WHY THE ERROR CAN STILL HAPPEN
------------------------------
The error "auth/api-key-not-valid" means Google/Firebase is rejecting the
API key before the login can happen. This cannot be repaired by changing the
HTML login form.

DO THIS ONCE
------------
1. Open https://console.firebase.google.com/
2. Open project: borh-d7a41
3. Click the gear icon -> Project settings.
4. Scroll to "Your apps".
5. Open the Web app for this project.
6. Find "SDK setup and configuration" and select "Config".
7. Copy the COMPLETE firebaseConfig object.
8. Open firebase-runtime.js in this ZIP.
9. Replace the values inside firebaseConfig with the values Firebase gives you.
10. Save the file.
11. Upload the updated files to the GitHub repository.

IMPORTANT FOR GOOGLE CLOUD API KEY RESTRICTIONS
------------------------------------------------

https://tcss2026-byte.github.io/Registration-form/*
